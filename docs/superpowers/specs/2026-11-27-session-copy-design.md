# 会话鼠标选中与复制设计

> 已替代：用户最终选择 Windows Terminal 原生选区（Shift+拖选），不实施下述应用内拖选及剪贴板设计。会话保留现有滚动行为，并通过启动提示和 CLI 文档说明终端选择与复制；快捷键取决于终端配置。下文保留为原方案记录。

## 目标与范围

以 Windows Terminal 中的交互会话为主要支持环境，允许用户在保留鼠标滚轮及键盘滚动的同时，使用鼠标拖选可见会话内容并复制。保持现有审核界面的鼠标模式交接和退出清理，不更改业务会话及持久化格式。其他终端、远程 SSH 和 tmux 的剪贴板兼容性不作保证。

## 交互

- 在对话视口内按住鼠标左键拖动创建选区，并即时高亮；松开结束选择。单击不复制，也不改变输入框内容。
- 使用 Ctrl+C 复制非空选区；没有选区时保留现有中断执行及退出提示行为。复制成功或失败均显示简短状态，失败不声称成功。选区以可见内容为范围，不支持跨屏自动选择；滚动、窗口尺寸变化或消息内容变化时清除选区，防止复制与高亮不一致。
- 鼠标滚轮、PageUp/PageDown、上下方向键的原有行为不变。标题、消息和可见执行提示均可选择，输入框和滚动条不在选区内。

## 实现边界

- 在会话期间启用终端按钮拖动报告及 SGR 编码，离开会话或进入审核时完整关闭并恢复；解析按下、移动、松开和滚轮事件，确保事件不会落入文本输入。处理分片和连续鼠标序列时不丢弃或误插入普通输入。
- 以实际屏幕渲染结果为选区和复制的共同数据源，不能从原始消息假设换行。选区按终端显示单元格映射 Unicode 字素和双宽字符，跨行文本按显示行顺序连接；不复制控制序列或样式。包含软换行时按屏幕显示换行复制，必要的行尾空白去除。
- Windows 本地剪贴板由宿主适配器提供异步写入，使用标准输入传递文本而非拼接 shell 命令，避免内容被当作命令执行。无支持平台或写入失败时显示失败提示；不要记录复制内容。剪贴板操作是用户主动触发，不后台复制。
- 选区视觉效果和取词必须使用同一帧；异步重绘期间不得读取已过期的坐标映射。保留安全文本过滤及 Windows 末列处理。

## 验证

- 先编写失败测试，再实现：鼠标协议和生命周期、正反方向拖选、中文和宽字符、多行及换行、渲染变化时选区清除、复制成功与失败、无选区 Ctrl+C、中断、滚轮及键盘回归、审核交接和恶意控制字符。
- 运行 TUI 和 CLI 相关测试、类型检查与完整测试；单独报告已有基线超时及任何未通过项。
- 在可用的真实 Windows Terminal 中手动检查选区高亮、剪贴板内容、滚轮和退出后鼠标状态。若当前环境无法执行真实交互，明确说明未验证，不以模拟测试替代实际验证结论。
