# 计划 3 独立基础能力设计

日期：2026-11-13。范围已经用户确认；本批不依赖计划 2 未提交接口。

## 目标与边界

本批分为两个可独立测试的子项目：发现事实的 discovery，以及生成条款草稿的 reqs 服务。只使用计划 1 已提交的 core/models/agent 接口，不接入 CLI/TUI，不写入被测项目，不创建 git 提交。

- discovery 从指定项目内的本地文件读取事实，不执行发现到的命令，不访问网络，不读取真实 `.env`，不生成或确认正式画像。
- reqs 只接收调用方显式提供的需求文档内容和模块名；不提供源码、文件或网络工具，不覆盖已有条款，不自动确认。
- Node.js ≥ 22.12，ESM，pnpm 9；代码注释、错误、文档使用中文。
- 测试使用临时目录与假模型，不访问网络、不消耗真实 token。

## 子项目 A：discovery

新增 `@crosscheck/discovery`，依赖 yaml，不依赖计划 2 的 Profile。插件输入为只读的有限文件读取接口与 AbortSignal，输出为事实候选和诊断。事实携带文件、行号、摘录和插件来源；事实是观察，不是授权或判定。受信任的进程内插件必须遵守只读契约；此接口不是恶意插件的安全沙箱。

文件读取限定项目根目录内，拒绝绝对路径、父路径、真实路径越界、符号链接和真实凭证文件；限制单文件大小。通用扫描仅检查有限的已知文件名，不遍历 node_modules 或任意业务代码。缺文件正常跳过；非法文件返回不含原始敏感内容的诊断。取消信号应向上传播，不吞成普通诊断。

静态扫描处理根目录 README.md、package.json、pom.xml、compose.yaml/docker-compose.yml 及 `.env.example`。从结构化清单提取依赖/项目类型、script、端口和环境变量名；README 保留启动相关行候选，不执行、不推断真实性；pom 仅静态提取已知标识，不展开外部实体；env 仅输出键名。命令候选中的内联凭证使用占位标记，URL 凭证/查询不进入输出。来源摘录亦需去除敏感值。

OpenAPI 插件读取调用方指定的本地 JSON/YAML，支持 OpenAPI 3.0/3.1 及 Swagger 2 的 paths、operation、参数和来源。处理 path/operation 参数覆盖；仅解析当前文档内的 JSON Pointer 引用，限制循环。外部引用只诊断，不读取也不请求。遇到不支持版本、非法结构或无法解析的引用，不伪造完整接口。保留文档声明的 server/basePath，但不把它视为网络白名单或默认授权。

## 子项目 B：reqs 服务

新增 `@crosscheck/requirements`，复用 `runAgent`、`ClauseSchema`、`BudgetTracker` 和 `ModelCandidate`，保留条款数组 ID 唯一约束但以固定消息报告重复错误。输入为 `{module, documents, models, budget, signal?}`，文档是 `{file, text}`。输出复用 AgentResult 形状，done 时仅含 Clause[] 草稿。文件名是来源标识，不在服务内读盘。

入口验证模块名、文档名唯一、非空文本及输入大小。模型输入通过 JSON 序列化携带原文，明确文档是数据而非指令。输出 schema 除原有结构外还强制：条款 ID 属于指定模块、source.file 存在于输入、line 是有效的 1-based 行、excerpt 非空且从该行起与原文连续精确匹配（统一 CRLF/LF）。来源验证纳入 runAgent 输出校验，使失败进入现有最多三次校验反馈机制；不写入或自动确认。不能从摘录匹配证明条款语义正确，仍需人工审核。

## 验收与后续适配

每项能力先观察失败测试，再实现；验证不执行命令、拒绝越界与凭证读取、确定性结果、取消、非法格式、本地引用、来源虚构及输出重试。全仓测试和类型检查必须通过。计划 2 稳定后另做适配，将发现事实转换为正式画像，并接 CLI/TUI；本批不预设其 schema。
